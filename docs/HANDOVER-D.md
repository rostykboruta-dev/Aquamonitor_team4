## 1. Зроблено
* Реалізовано функцію `aggregate_by_period(series: Series, period: Literal["day", "week", "month"])` у модулі `src/aquamonitor/analytics.py`. Функція здійснює групування спостережень за добою (`YYYY-MM-DD`), тижнем (`YYYY-Www`) або місяцем (`YYYY-MM`).
* Для кожного періоду обчислюються статистичні агрегати: мінімум (`min`), максимум (`max`), середнє (`avg`), загальна кількість записів (`count`) та кількість пропусків (`missing_count`).
* Реалізовано функцію `generate_console_report(series, period)`, яка формує та виводить у консоль відформатовану таблицю зведеного звіту.
* Написано та успішно запущено юніт-тести в `tests/test_analytics.py`.

## 2. Не зроблено
* Побудова та збереження лінійного графіка залежності рівня від часу в PNG-файл (`build_time_series_plot` згідно з `spec.md`).
* Збереження текстового або CSV-звіту у файл при передачі шляху збереження.

## 3. Ухвалені рішення
* Формування ключа тижня здійснюється за стандартом ISO `obs.timestamp.isocalendar()` у форматі `YYYY-Www`.
* Для доступу до списку спостережень використовується приватний атрибут `_observations` класу `Series`.
* Усі значення агрегатів (`min`, `max`, `avg`) заокруглюються до 2 знаків після коми (`round(..., 2)`).
* Якщо для періоду всі дані відсутні (`None`), повертаються значення `0.0` для `min`, `max` та `avg`.

## 4. Проблеми
* Пряме використання приватного поля `series._observations` є доступом до внутрішніх деталей класу `Series` (у майбутньому доцільно додати публічний getter або підтримку ітератора у `domain.py`).

## 5. Далі
* Реалізувати функцію побудови та збереження графіків `build_time_series_plot(series, output_path)` за допомогою бібліотеки `matplotlib`.
* Інтегрувати зводку з CLI-підкомандою `aquamonitor report`.

## 6. Обережно
* Параметр `period` у `aggregate_by_period` приймає суворо значення `"day"`, `"week"` або `"month"`. Передача будь-яких інших значень (наприклад, `"year"`) викликає `ValueError`.
* Переконуйтеся, що об'єкти `Observation` у `Series` містять часову зону (`tzinfo`), як того вимагає модель `domain.py`.

## 7. Як запустити
1. Переконайтеся, що ви перебуваєте в корені репозиторію та активовано віртуальне середовище (`.venv`).
2. Запустіть тести аналітики через `unittest`:
   ```bash
   PYTHONPATH=src python -m unittest tests/test_analytics.py
   ```
